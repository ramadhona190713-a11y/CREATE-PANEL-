# Hermes Quickstart

Setup sekali jalan, langsung pakai Hermes Agent. Wajib login dulu!

## Install
```bash
git clone https://github.com/YOURNAME/hermes-quickstart.git
cd hermes-quickstart
bash setup.sh
```

## Login (jika belum)
```bash
hermes auth add
```

## Cek status
```bash
hermes auth status nous
hermes model
```
